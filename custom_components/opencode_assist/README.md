# OpenCode Assist companion

The companion now lives inside the beta image's build context so automatic
installation and the release ZIP use exactly the same source.

See the [installation, restart and pairing guide](../../ha_opencode_beta/rootfs/opt/opencode-assist/custom_components/opencode_assist/README.md).
For manual installation, use `opencode-assist.zip` from the matching beta release;
this compatibility documentation directory is not an installable integration.
