# OpenCode Assist companion

The companion lives inside each channel's image build context so automatic
installation and that release's ZIP use exactly the same source.

See the [stable installation, restart and Supervisor onboarding guide](../../ha_opencode/rootfs/opt/opencode-assist/custom_components/opencode_assist/README.md)
or the [beta guide](../../ha_opencode_beta/rootfs/opt/opencode-assist/custom_components/opencode_assist/README.md).
Enable Assist in the selected app to install its bundled companion. This compatibility
documentation directory is not an installable integration.
