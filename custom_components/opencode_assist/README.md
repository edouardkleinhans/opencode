# OpenCode Assist companion

The companion now lives inside the beta image's build context so automatic
installation and the release ZIP use exactly the same source.

See the [installation, restart and Supervisor onboarding guide](../../ha_opencode_beta/rootfs/opt/opencode-assist/custom_components/opencode_assist/README.md).
Enable Assist in the beta app to install its bundled companion. This compatibility
documentation directory is not an installable integration.
